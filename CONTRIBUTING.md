# Contributing

Thanks for contributing to Dirigo Strategic Advisors.

The full engineering workflow lives in the private
[`engineering-standards`](https://github.com/Dirigo-Strategic-Advisors/engineering-standards)
repository (ask an organization owner for access). The essentials:

- Branch off `main` using `feature/*`, `fix/*`, `hotfix/*`, or `chore/*`.
- Use [Conventional Commits](https://www.conventionalcommits.org/).
- Open a pull request, fill in the template, and link your issue.
- CI must pass and conversations must be resolved before a **squash merge**.
- Never commit secrets. Never force-push to `main`.

Be professional and respectful — see [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
