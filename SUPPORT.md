# Support

## Where to get help

| Need | Where |
|------|-------|
| Bug or defect | Open a **Bug report** issue in the affected repository |
| Feature idea | Open a **Feature request** issue |
| How do I...? | Start a discussion in `engineering-standards`, or read the handbook |
| Access to a repository | See the access-request process in the handbook (or contact an org owner) |
| Security issue | **Do not** open an issue — see [SECURITY.md](SECURITY.md) |
| Production incident | Follow the incident process; page the on-call owner |

## New engineers

Start with the Developer Onboarding guide in the private `engineering-standards`
repository.
